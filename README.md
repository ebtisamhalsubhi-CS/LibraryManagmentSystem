# Library Management System

A library management system written in Java, with a web interface.

- Keep books on the shelf: add, view, search (by ID, title, or author), update, and delete
- Add and view members
- Borrow books for 14 days and return them
- Create an account and log in

## Run it

- **Website:** run `WebServer.java`, then open http://localhost:8080
- **Console version:** run `Main.java`

Built with Java (OOP, inheritance, enums, ArrayList), HTML, CSS, and JavaScript.
